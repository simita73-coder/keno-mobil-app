# Keno NC – mobil

Androidos változat (Flet / Python). A számolás a `src/keno_core.py`-ban van,
ugyanaz a fájl, mint az asztali programban.

- Adatok a telefonon: `/Norbi/Keno/` (keno.db, keno.csv, Keno.xlsx)
- Első induláskor kell: **Minden fájl kezelése** engedély
- APK: a **Releases → Legfrissebb Keno NC APK** alól (minden feltöltés után magától épül)
